BULK 85 — دليل النشر المجاني

محتويات الحزمة:
- index.html: التطبيق
- manifest.json وأيقونات التطبيق: إضافة للشاشة الرئيسية
- sw.js: تخزين ملفات التطبيق للعمل دون اتصال بعد أول زيارة

النشر عبر GitHub Pages:
1) أنشئ حساباً على github.com ثم مستودعاً جديداً باسم bulk85.
2) ارفع الملفات الخمسة الموجودة في هذه الحزمة إلى جذر المستودع (index.html وmanifest.json وsw.js وicon-192.png وicon-512.png).
3) افتح Settings ثم Pages.
4) في Build and deployment اختر Deploy from a branch.
5) اختر main ثم /(root) واضغط Save.
6) بعد اكتمال النشر افتح الرابط الذي يظهر لك في Pages.
7) في Safari على iPhone اضغط زر المشاركة ثم Add to Home Screen ثم Add.

الخصوصية:
- الوجبات والأوزان والصور تحفظ في Local Storage على نفس متصفح الجهاز.
- لا توجد حسابات ولا مزامنة سحابية ولا اتصال بخدمة تحليل صور.
- موقع GitHub Pages نفسه عام ويمكن لأي شخص فتح واجهته؛ لا تضع بياناتك الشخصية في ملفات المستودع.
- GitHub يسجل بيانات زيارات الموقع لأغراض الأمان.
- لا تستخدم التصفح الخاص، ولا تمسح بيانات Safari إذا تبي تحتفظ بالسجل.
- صدّر نسخة احتياطية من صفحة السجل دورياً.

تنبيه:
هذه النسخة لا تحلل الصور بالذكاء الاصطناعي. التحليل السحابي يعني إرسال صورة الوجبة لخدمة خارجية، وهذا لا يطابق شرط أن تبقى كل البيانات على جهازك فقط.
